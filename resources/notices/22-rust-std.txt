Rust standard library (std, core, alloc and the crates it is built with)
https://github.com/rust-lang/rust
Statically linked into ssw-capture.exe, ssw-speech.exe and ssw-speech-compat.exe, which are built
with Rust 1.88 or newer. Besides std, core and alloc, the Rust toolchain builds crates such as
addr2line, adler2, cfg-if, compiler_builtins, gimli, hashbrown, memchr, miniz_oxide, object,
rustc-demangle and windows-link into the standard library.
