# Caption fonts

The fonts Captions Studio draws with (docs/design/captions-studio.md §6, §0.1, §0.2), referred to as
`cat:<id>` and listed in `src/shared/captions/fontCatalog.ts`, which pins every file.

- **Source**: google/fonts at commit `6c1dbe27dcf7d817d4b62cec033ba77fa8e2a5ec`, and the colour emoji from
  googlefonts/noto-emoji at tag `v2026-09-24-unicode18_0` (commit `e20cbc2bbec1926686be9f9bee7d1d2cfa1fea0e`).
- **Format**: each bundled file is the upstream TTF in a WOFF2 container. Every table of the TTF is kept
  byte for byte (WOFF2 null transforms) and only compressed (brotli), so the fonts are not changed;
  `node scripts/fonts.mjs check` proves it by decoding each WOFF2 against its pinned TTF.
- **Rebuild**: `node scripts/fonts.mjs download` fetches the pinned TTFs (each checked by size and
  SHA-256) and `node scripts/fonts.mjs build` writes the WOFF2 files.
- **Licences**: SIL Open Font License 1.1 (`LICENSES/OFL-1.1.txt`), Luckiest Guy and Permanent Marker
  Apache License 2.0 (`LICENSES/Apache-2.0.txt`). The copyright lines are in
  `resources/notices/34-caption-fonts.txt`. The fonts are never offered on their own (OFL condition 1).

42 bundled files: 17.11 MB as TTF, 7.47 MB as WOFF2.
