# Build report: captions (Wave 4)

Branch `feat-w4-captions`, built on `2144728`. Captions are generated by an AI provider (through the
AI builder's `window.api` contract), edited in the Captions tab and on a timeline track, drawn on the
video (preview and export through `drawFrame`), and exported as SRT, WebVTT or plain text.

## What was built

### Pure logic (`src/shared/captions/`, unit-tested)
- **`layout.ts`**: the caption at a source time (binary search); its words with times (the provider's
  word timings while the text still has that many words, else spread over the caption by length);
  line breaking to the safe width (a word too long for a line is broken between letters); grouping
  into chunks of at most `maxLines` lines shown one after another, each timed by its first word;
  two-line chunks evened out; the karaoke word (last word that has started); fades of 0.12 s in
  **viewing time** (like `titleCards.ts`, so cuts and speed changes neither jump nor stretch them),
  none between captions that follow within 0.25 s; placement at the bottom / middle / top inside safe
  margins. Text is measured at one reference size and scaled, so preview and export break the same words.
- **`subtitles.ts`**: captions in **output time**: dropped inside cuts, clipped at cut edges (a caption
  across a cut is one cue without the cut time), scaled by clip speed; with matching word timings, words
  whose middle was cut are left out. SRT (`HH:MM:SS,mmm`, lines ≤ 42 chars), WebVTT (header, `&<>`
  escaped), plain text; `-->` in text is defused; cues never overlap. `validSubtitle()` is the check the
  main process repeats before writing.
- **`edit.ts`**: drag bounds and drag times (no overlaps, minimum 0.2 s), word timings moved with a
  caption, split at the playhead (at the spoken word), merge with next, find / replace (case-insensitive,
  literal), `applyTextResult()` (an AI cleanup/translation is applied only if ids, order and times match
  within 1 ms and every text is non-empty), `readSuggestedChapters()`.
- **`settings.ts`**: defaults, the five presets (clean, bold, boxed, karaoke, minimal: weight, capitals,
  outline, karaoke highlighting, scale), `readCaptionSettings()`.
- **`captionData.ts`**: `readTranscript()` / `readCaptionSegments()`: malformed segments and words
  dropped, times clamped to the recording, sorted, overlaps removed, one-line clean text, unique ids.
- **`src/shared/engine/project.ts`**: `migrateProject` reads `transcript` and `captions` with these
  readers (absent stays absent: no `undefined` keys in saved files).

### Renderer
- **`render/captionsLayer.ts`**: returns before any work without a transcript or with captions hidden.
  Layouts are cached per caption object (WeakMap; edits replace objects); each chunk is painted once
  into a sprite keyed by caption, chunk, spoken word, look and size (background box per line, outline,
  shadow, karaoke pill), and per frame only `drawImage` with the fade as alpha. At most 6 sprites, whose
  canvases are reused, so playback never allocates canvases once warm. Dark text gets a light box/outline.
- **`editor/panels/CaptionsPanel.tsx`** + **`editor/captions.css`**: empty state explaining captions;
  Generate (transcription-capable providers only, spoken language Auto + 25 languages incl. English,
  Bengali, Hindi, Spanish, sound source Auto / Microphone / Mixed when the recording kept stems, progress
  from `onTranscribeProgress` with Cancel, readable errors); "Add an AI provider" (dispatches
  `ssw:open-settings` with `{ section: 'ai' }`) when no provider can transcribe, with a Claude-only
  explanation; Regenerate with confirmation. The transcript and `captions.show = true` are stored in one
  undo step. Look section (show, presets with samples, position, size, text and highlight colours,
  background, lines). Transcript editor (output-time stamps, editable text, click seeks, current caption
  highlighted while playing, split / merge / delete, find & replace, paging over 150 rows). AI tools with
  a provider picker over all providers: Fix captions, Translate to…, Suggest chapters (one undo step,
  skips chapters already there), Suggest a title (offers to rename). Export captions (format chips +
  save dialog).
- **`editor/captionItems.ts`** (new): request channel from the commands / track to the tab, the
  transcription job (keeps running and stores its result when another tab is open), `showCaption()`.
- **`editor/CaptionTrack.tsx`**: block per caption labelled with its text; click selects (opens the tab)
  and seeks past the fade-in; edges trim and the middle moves, bounded by the neighbours (one undo step
  per drag); double-click focuses its text in the tab; label row only with a transcript; dimmed when
  captions are hidden.

### Main / preload
- **`src/main/captionsIpc.ts`** (`captions:save`): validates format and content (before showing the
  dialog), suggests a sanitised file name in Videos, writes only the dialog's absolute path with the
  format's extension (atomic write; SRT with a UTF-8 BOM for older Windows players).
- **`src/shared/api/captions.ts`**, **`src/preload/captions.ts`**; registered in `src/shared/api.ts`,
  `src/preload/index.ts`, `src/main/index.ts`.

### Commands (`src/shared/editor/commands.ts`, actions in `views/Editor.tsx`)
New category **Captions**: *Generate captions*, *Show or hide captions* (toggle; unavailable without
captions), *Export captions…* (unavailable without captions); plus *Open Captions settings* (Panels).
No default keys (`DEFAULT_KEYMAP` gives every command `[]` automatically, so `shortcuts.ts` needed no
change).

## For the AI builder
- The tab re-reads `listAiProviders()` when it opens, when the window regains focus, on "Check again",
  and on a window event **`ssw:ai-providers-changed`**: dispatching it after providers are saved or
  removed makes the tab update at once.
- Transcripts returned by `transcribe()` go through `readTranscript()` before they are stored (bad
  segments dropped, times clamped); an empty result shows "No speech was found in this recording".
- Progress is matched on `progress.projectId`; phases `extracting/uploading/transcribing/finishing` and
  `done/total` are shown ("Part n of m" when total > 1).
- `aiText` results are checked: `task` must match the request; cleanup/translate must return the same
  ids in order with times within 1 ms. The UI refuses to apply if the captions changed while waiting.

## Known gaps
- Transcription and AI text tasks run against the stubs on this branch; the e2e covers the UI with
  providers injected into the main process (a fake provider list, a fake `ai:text`), not real providers.
- Caption times are clamped to the recording when a project loads, but not by `correctProjectMedia`
  when the opened video turns out shorter (not my file); captions past the end are simply never shown.
- The transcript list pages at 150 rows instead of virtualising; very long transcripts page through.
- Caption text is a single line per caption (line breaks become spaces); there is no per-word editing of
  timings beyond split / merge and the track drags.
- The fade, chunking and karaoke timing are unit-tested; the e2e checks pixels at chosen frames (times,
  position, box vs shadow, karaoke word moving, a cut) rather than fade curves.
